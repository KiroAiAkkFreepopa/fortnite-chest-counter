# 🎮 Fortnite Chest Counter

**Fortnite Chest Counter** — программа для автоматического подсчёта открытых сундуков в Fortnite.

Программа самостоятельно отслеживает открытие сундуков во время игрового процесса и автоматически обновляет счётчик. Больше не нужно считать сундуки вручную — просто играй, а программа сделает всё за тебя!

### ✨ Возможности
- 📦 Автоматическое обнаружение открытых сундуков.
- 🔢 Подсчёт количества открытых сундуков в реальном времени.
- ⚡ Быстрая и удобная работа.
- 🎯 Автоматизация без необходимости ручного подсчёта.
- 🖥️ Удобное меню управления.

### 🚀 Установка и запуск
1. Скачайте файлы проекта.
2. Запустите `FortniteChestCounter.exe`.
3. Запустите Fortnite и играйте.
4. Откройте меню программы клавишей `Insert` или `Delete`.

###❗️ВНИМАНИЕ
Для работы 'Автоподсчёт после игры, по реплею'
надо включить реплеи после игры
